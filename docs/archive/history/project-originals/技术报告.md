---

## 一、作品概述

「秩研Agent」是面向**线性代数**学科的垂类智能助学系统，围绕高校《线性代数》教学中的真实痛点（概念抽象难懂、公式推导繁琐、作业批改负担重、学情难追踪），提供智能问答、可验证求解、知识图谱、错题归因、学习画像等完整功能闭环。

系统采用 **「大模型 + RAG + 本地可验证求解引擎」三引擎协同架构**：
- **DeepSeek 大模型**：负责自然语言理解、讲解生成、多轮对话；
- **RAG 知识库**：基于同济版《线性代数》第六版构建结构化知识库，BM25 检索注入上下文，确保内容权威可信、可溯源；
- **本地可验证求解引擎**（SymPy 符号计算 + NumPy 数值回代）：对数学计算类问题做**确定性计算**，从根源上消除大模型数学幻觉。

## 二、系统架构

```
用户（浏览器前端）
   │  fetch /api/ask
   ▼
┌───────────────────── FastAPI 后端 ─────────────────────┐
│ 1. 意图识别与问题解析                                     │
│ 2. 引擎前置校验（数学计算类）                             │
│    ┌──────────────────────────────┐                     │
│    │ 本地可验证求解引擎             │                     │
│    │ · SymPy 符号计算（精确）       │                     │
│    │ · NumPy 数值回代（验证）       │                     │
│    │ · 行列式/逆/特征值/方程组/秩   │                     │
│    └──────────────────────────────┘                     │
│ 3. RAG 知识检索（BM25，同济教材知识库）                   │
│ 4. DeepSeek 大模型生成（基于引擎结论 + 知识库组织讲解）    │
│ 5. 积分系统：token 消耗追踪与用户权益                     │
└──────────────────────────────────────────────────────────┘
```

**双引擎纠错机制**（核心技术亮点）：
```
数学问题 → 本地引擎确定性计算 → 结果注入 prompt（强制为基准）
        → 大模型基于验证结论组织讲解（不再自行计算关键数值）
```
该机制在测试中成功发现并修复了大模型对含参方程组行列式的计算幻觉（详见《效果验证报告》）。

## 三、技术实现

### 3.1 知识库构建（对应赛题技术点①）
- 以同济版《线性代数》第六版为核心知识源，覆盖 **6 大章节、24 个知识点**；
- 教材电子版分页处理（`textbook_pages/`），构建结构化知识语料 `knowledge_corpus.json`（含章节、小节、知识点、公式）；
- 知识点间建立**前置依赖图谱**（`knowledge_graph.py`），支撑自适应学习路径规划。

### 3.2 检索增强生成 RAG（对应赛题技术点③）
- 自研中文 BM25 检索器（`retrieval.py`），核心检索功能不依赖外部第三方服务；
- 检索命中知识片段作为上下文注入，要求模型**优先依据知识库作答并标注出处**；
- 回答返回 `citations`（出处溯源）与 `sources`（知识片段），实现**内容可追溯**（评分点4）。

### 3.3 可验证求解引擎（对应赛题技术点②④，创新拓展）
- 16 种矩阵运算：行列式、逆矩阵、秩、特征值、特征向量、对角化、SVD、QR 分解、零空间、线性方程组（含**参数方程组讨论**）、正交投影等；
- **符号计算**（SymPy 精确解）+ **数值回代验证**（NumPy 残差检查）双保险；
- 支持自然语言直接提问（如"讨论含参数a的方程组解的情况"），引擎自动解析并给出分情况结论。

### 3.4 智能工作流编排（对应赛题技术点④）
- **自动出题** `/api/workflow/quiz`：RAG 检索 → LLM 生成结构化小测验；
- **分步解题** `/api/workflow/solve`：分类 → 检索 → 求解 → 验证；
- **错题诊断** `/api/workflow/diagnose`：定位错误 → 解释 → 纠正路径。

### 3.5 多模态交互（对应赛题技术点⑤）
- 接入讯飞星火视觉模型 `spark-x`，支持**拍照题目识别**；
- 前端 KaTeX 数学公式渲染、矩阵可视化编辑器、几何动态演示（向量/线性变换动画）。

### 3.6 个性化与自适应（评分点8）
- **学习画像**：知识掌握度（含艾宾浩斯遗忘曲线）、VARK 学习风格、认知能力、兴趣向量、情绪趋势（EMA）、学习节律 6 维建模；
- **自适应学习路径**：基于知识点前置依赖图（拓扑排序）+ 薄弱点传播（BFS）动态推荐。

### 3.7 学习过程陪伴（对应赛题助学场景）
- 错题本自动归因到知识点；
- 智能体模拟导师/学伴，苏格拉底式引导解题（`guided` 模式）。

## 六、部署与运行

### 6.1 本地运行
```bash
cd backend
pip install -r requirements.txt
cp .env.example .env   # 填入 API 密钥（已内置 DeepSeek 配置）
python run.py          # 或 uvicorn main:app --host 0.0.0.0 --port 8000
```
访问 http://localhost:8000

### 6.2 环境变量
| 变量 | 说明 |
|------|------|
| `LLM_API_KEY` | DeepSeek API 密钥 |
| `LLM_BASE_URL` | `https://api.deepseek.com` |
| `LLM_MODEL` | `deepseek-chat` |
| `LLM_VISION_*` | 讯飞星火视觉模型（图片识别） |
| `RAG_ENABLED` / `RAG_TOP_K` | RAG 开关与召回数 |

### 6.3 生产部署
- **Docker**：`docker build -t zhiyan-agent . && docker run -p 8000:8000 zhiyan-agent`
- **云平台**：Render / Railway / 腾讯云函数，上传本目录 + `.env` 即得公网地址
- **Demo 地址**：https://aff7f7c6ba1b6fb80.bj5.agentos-app.net

## 七、复现指南

1. 安装依赖 → 配置 `.env` → 启动服务；
2. 打开首页 → 注册账号 → 进入各功能模块；
3. **复现测试案例**（见《效果验证报告》）：
   - 智能问答输入 `求矩阵A=[[2,1],[1,2]]的特征值和特征向量`
   - 输入 `讨论含参数a的线性方程组 ax+y+z=1, x+ay+z=a, x+y+az=a^2 解的情况`
   - 观察回答中的引擎校验标记 `engine_verified: true`
4. 知识库更新：修改 `js/knowledge.js` 后执行 `node build_corpus.js` 重新生成语料。

## 八、创新点总结

1. **双引擎纠错架构**：大模型 + 本地可验证求解引擎，数学计算类问题 100% 确定性正确；
2. **含参方程组自动分析**：从自然语言解析符号方程组，自动分情况讨论（唯一解/无解/无穷多解）；
3. **学习画像六维建模**：知识掌握度 × 学习风格 × 认知能力 × 兴趣 × 情绪 × 节律；
4. **自适应路径**：知识点前置图拓扑排序 + 薄弱点传播的 BFS 推荐；
5. **多模型协同**：DeepSeek（主对话）+ 讯飞星火（多模态）+ 本地引擎（计算），各司其职。
