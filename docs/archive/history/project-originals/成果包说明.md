## 二、部署方式

```bash
# 方式一：直接运行（Python 3.11+）
pip install -r requirements.txt
python run.py            # 启动主服务（默认端口见 run.py）

# 方式二：Docker
docker build -t rank-tutor .
docker run -p 8000:8000 rank-tutor
```

部署细节见包内 `DEPLOY.md`。

## 四、核心功能清单

1. **智能问答**：自然语言提问、意图识别、概念查询、分步引导解题（RAG 增强）
2. **知识体系**：6 大章节、18+ 知识点，知识图谱可视化
3. **计算工具**：16 种矩阵运算、可视化矩阵方格编辑器（1-10 阶）、分步计算展示
4. **练习中心**：118 道题库（概念/计算/证明/判断/填空），变式题、错题本、学习画像
5. **几何可视化**：向量运算动态演示、线性变换动画
6. **自进化训练**：基于问答日志持续扩充知识语料、迭代模型版本
