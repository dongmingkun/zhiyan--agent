## 一、作品阐述

### 1.1 项目定位

**秩研Agent** 是一款面向"一流学科建设"的**学科垂类大模型智能助学系统**，聚焦高校线性代数课程。它不是"通用大模型的简单套壳"，而是一个**"能算、能验、可追溯"**的垂类助学智能体——通过深度对接教材、学科工具与学情数据，解决通用大模型在数学教学场景下的四大痛点：

| 痛点 | 通用大模型表现 | 秩研Agent 解法 |
|---|---|---|
| **会聊天，不会算** | 给结果但无法验证，错答不知 | SymPy + NumPy **三重交叉验证**，每步可追溯 |
| **概念泛化，不贴教材** | 不契合同济版章节体系 | 553 条**章节化知识库** + RAG 检索 + 引用溯源 |
| **学情无感知** | 讲完即忘，无个性化 | 八维能力画像 + 错题雷达 + 薄弱点联动 |
| **公式呈现/多模态差** | LaTeX 渲染混乱、看不到图 | 精细 LaTeX 渲染 + **三级视觉降级**（星火图片理解 / OpenAI 兼容 / RapidOCR） |

### 1.2 核心价值观

> **"不是背答案，而是验证答案"** —— 线性代数不是公式背诵，而是通过符号变换理解空间结构。系统让学生看到每一步计算怎么来、为什么对、错在哪。

### 1.3 应用场景

- **日常学习**：拍照搜题、概念查询、矩阵计算、几何动画演示
- **考前复习**：错题雷达、章节掌握度、薄弱点聚焦、定向训练
- **教学辅助**：教师出题、可验证解题、试卷库检索、学术文献支撑
- **移动端学习**：PWA + APK 双形态，离线可用，全屏运行

### 2.2 智能问答模块

**三种教学模式适配不同学习阶段**：

| 模式 | 风格 | 适用场景 |
|---|---|---|
| **直接解答** (direct) | 先给核心结论 + 关键步骤，≤500 字 | 快速查题、即时答疑 |
| **分步讲解** (detailed) | 完整推导过程 + 依据，≤1500 字 | 系统学习、概念理解 |
| **引导学习** (guided) | 苏格拉底式提问，先想后教 | 自学探究、深度理解 |

**领域守门**（防止无关问题消耗 token）：对游戏/股票/旅游等明显无关问题，按类别（8 类）给出贴合主题的"灵活引导"回复，自然过渡到线代应用场景（如"游戏 → 骨骼动画矩阵"、"金融 → PCA 风险模型"）。

**图片问答三级降级链路**：
```
① 科大讯飞星火图片理解(优先) → ② OpenAI 兼容视觉 → ③ RapidOCR + 主 LLM
   WebSocket 流式，domain=imagev3     兜底视觉           文字 OCR 兜底
```

**RAG 检索增强**：本地向量/关键词混合检索 + 动态 Few-shot 例题注入 + 引用出处溯源弹窗（每条知识卡可展开"拓扑图谱"看关联知识）。

**知识拓扑图谱**：力导向图 + 前置依赖权重 + 薄弱点聚焦联动（点击薄弱知识点自动跳转学习路径）。

### 2.4 计算工具模块（核心差异化）

**16 种矩阵运算**全部支持**符号解 + 数值解 + 回代验证**三重交叉：

| 类别 | 支持运算 |
|---|---|
| **基础运算** | det、rank、inverse、transpose、trace |
| **特征分解** | eigenvalues/eigenvectors、diagonalize |
| **矩阵分解** | QR、SVD、LU、Cholesky |
| **空间分析** | nullspace、column space、row space、orthogonal projection |
| **方程组** | solve_linear（含参数化分析） |

**核心差异化**：所有计算结果 **能跑（执行）、能验（回代）、可追溯（步骤展示）**——相较直接依赖通用大模型生成结果，本系统通过计算引擎回代校验，可显著降低计算类题目的出错率。

### 2.5 几何可视化模块

- **向量运算动态演示**：加法 / 数乘 / 内积 / 叉积 / 投影，2D-3D 实时动画
- **线性变换动画**：矩阵乘法对应空间变换，基向量轨迹直观可见
- **特征向量可视化**：变换下方向不变的向量，直观理解 Av=λv

### 2.6 辅助能力

- **学习画像**：八维能力雷达图（计算/概念/几何/证明/应用/理解/速度/准确）+ 情绪曲线。**非静态展示**——背后有真实诊断闭环：
  1. 答题结果 → `knowledge_mastery` 表更新（mastery_score / attempts / correct_attempts / **forgetting_score 遗忘曲线**）
  2. 错题 → `/api/mistakes/recommend` 做**错题分类 + 知识点映射 + 能力估计**，返回 `weak_points` 薄弱点列表
  3. 薄弱点 → 前端高亮知识图谱节点 → 跳转定向训练路径（薄弱路径最易错环节定位）
- **错题本**：自动错题沉淀 + 错题雷达 + 智能回顾
- **测试中心**：在线测验 + 练习题库 + 试卷库（复旦/西南交大等出版社）
- **教学资源**：学术文献库（图论/数值线性代数/知识图谱等）+ 电子教材
- **社区**：好友 / 群组 / 动态 / 私信
- **管理后台**：用户管理 + 开发者控制台 + 数据看板

### 3.3 核心算法

**RAG 检索**：
- 输入：用户问题 + 模式
- 召回：BM25 关键词 + 局部向量相似度（轻量嵌入），混合打分
- 排序：取 Top-K (默认 5，流式 2)
- 注入：作为 system prompt 前缀，附 `RAG_INSTRUCTION` 强化引用

**可验证计算引擎**：
```python
def solve(task, matrix):
    # 1. SymPy 符号解（精确，无浮点误差）
    sym = sympy_compute(task, matrix)
    # 2. NumPy 数值解（快速回代）
    num = numpy_compute(task, matrix)
    # 3. 回代验证（结果代入原方程检查）
    verify = cross_check(sym, num, original=matrix)
    return {'symbolic': sym, 'numeric': num, 'verified': verify}
```

**视觉三级降级**：
```
请求 → 星火图片理解(WebSocket) → 成功？→ 流式返回
                                          ↓ 失败
                                       OpenAI 兼容视觉 → 成功？→ 流式返回
                                                          ↓ 失败
                                                       RapidOCR 提取文字
                                                                  ↓
                                                          主 LLM 基于文字解答
```

### 3.4 安全与性能

- **代码执行沙箱**：计算引擎隔离执行，防代码注入
- **登录鉴权**：JWT 签名令牌 + 频率限制
- **领域守门**：8 类无关问题按类别给贴合主题的引导回复
- **响应缓存**：相同问题 5 分钟内直接返回，节省 token
- **SSE 流式**：边生成边显示，首字延迟大幅降低
- **精简 Prompt**：prefill 长度压缩，冷启动提速
- **PWA + APK**：离线可用，移动端全屏运行

### 4.2 典型应用场景示例

**场景 1：拍照搜题（图片问答）**
- 用户拍照上传"求 n 阶矩阵 A=[[1,a,...,a],[a,1,...,a],...,[a,a,...,1]] 的特征值 (a≠0)"
- 系统先调星火图片理解 → 正确识别矩阵结构
- 给出答案：**λ₁ = 1+(n-1)a, λ₂ = ... = λₙ = 1-a**
- 展示完整推导（谱映射定理 / 秩一矩阵分解）
- 给出 n=3, a=2 的快速验证例题

**场景 2：手写/印刷题 OCR 兜底**
- 当星火视觉返回 10012 等临时错误时
- 系统自动降级到 RapidOCR 提取文字
- 主 LLM 基于文字内容继续解答
- 用户无感知，平滑过渡

**场景 3：错题雷达 + 薄弱点聚焦**
- 学生在"特征值"章节答错 3 题
- 系统自动降低该章节掌握度评分
- 知识图谱上"特征值"节点标红
- 点击聚焦 → 进入专项训练路径
- 推荐 5 道同类型练习 + 1 个核心知识点微课

**场景 4：无关问题灵活引导**
- 用户问"王者荣耀怎么玩"
- 系统识别为游戏类，不调 RAG（避免机械检索）
- 给出贴合主题的引导："🎮 游戏我玩得不多哦~ 不过线性代数在游戏里用处可大了 —— 3D 角色骨骼动画、相机矩阵变换都离不开它。要不要从线代角度了解一下？"

## 六、创新之处

### 6.1 学科垂类深度（最核心创新）

| 维度 | 通用大模型 | 秩研Agent |
|---|---|---|
| 计算结果 | 给出数字，无法验证 | SymPy 符号解 + NumPy 数值解 + 回代验证三重交叉 |
| 知识体系 | 通用训练数据 | 553 条章节化知识库 + RAG + 引用溯源 |
| 教学规范 | 自由回答 | 三种教学模式适配不同学习阶段 |
| 公式呈现 | 经常渲染失败 | 精细 LaTeX 渲染 + 数学符号体系 |
| 学情闭环 | 无 | 八维画像 + 错题雷达 + 薄弱点联动 |

### 6.2 可验证计算引擎（差异化壁垒）

面向线性代数学科场景设计**"三引擎交叉验证"机制**——所有数学结果都经过：
- **SymPy 符号推导**（精确，无浮点误差）
- **NumPy 数值回代**（快速数值解）
- **回代核验**（结果代入原方程检查）

用户能清楚看到每一步的来龙去脉，**知道结果为什么对、错在哪**——相较直接依赖通用大模型生成结果，计算引擎回代校验可显著降低计算类题目的出错率。

### 6.3 多模态三级降级链路（鲁棒性创新）

针对图片问答场景设计：
- **第一优先级**：星火图片理解（专业视觉模型）
- **第二优先级**：OpenAI 兼容视觉（可扩展）
- **第三优先级**：RapidOCR + 主 LLM（保证始终可用）

加上 **10012 等临时错误的自动重试机制**，确保任何网络/服务异常下都能给出答案。

### 6.4 轻量前端（普惠性创新）

前端核心问答与计算功能不依赖外部第三方服务（不引入 React/Vue/任何 UI 库），只用 HTML5 + CSS3 + JavaScript + Canvas：
- **首屏加载 < 200KB**（不含知识库）
- **离线可用**（PWA + Service Worker）
- **可打包成 APK**（Cordova 套壳，144KB）
- **可部署到任何环境**（单 FastAPI 端口 + 静态文件）

这对教育普惠意义重大——**低配电脑、偏远地区、老旧手机**都能流畅使用。

### 6.5 灵活领域守门（用户体验创新）

不机械拒绝所有无关问题，而是按 8 大类别（游戏/体育/金融/旅行/美食/学习/生活/健康）给出**贴合主题**的引导回复，把线代应用场景自然衔接：
- "股票" → "金融工程里 PCA 风险模型"
- "游戏" → "骨骼动画矩阵变换"
- "旅游" → "图论路径规划"

让用户在**闲聊中也能自然过渡到线代**，而不是冰冷的"抱歉不在范围"。

### 6.6 端到端竞赛级工程化

- **数据保护**：自动备份（保留最近 10 份），DB 重置时恢复内置账号
- **冷启动优化**：精简 prompt + 连接预热，首字延迟大幅降低
- **响应缓存**：相同问题 5 分钟内秒回
- **代码沙箱**：计算引擎隔离执行
- **零密钥泄露**：`.env.example` 模板化，源码包不含真实密钥
