# 秩研Agent · 部署说明

> 面向一流学科建设的学科垂类大模型与创新应用开发竞赛（赛题编号 XH-202620）
> 版本：v20260905 · 部署包

---

## 一、依赖安装

```bash
pip install -r requirements.txt
```

主要依赖：`fastapi`、`uvicorn`、`numpy`、`sympy`、`requests`、`pydantic`（详见 `requirements.txt`）。

## 二、环境变量配置

复制示例配置为本地 `.env`：

```bash
cp .env.example .env
```

然后编辑 `.env` 填入你自己的密钥（**示例文件内所有密钥值均为空，请勿上传真实密钥**）：

| 变量名 | 必填 | 说明 |
|--------|------|------|
| `LLM_API_KEY` | 是 | 大模型密钥（星火 APIPassword / DeepSeek / OpenAI 等） |
| `LLM_BASE_URL` | 是 | 大模型 OpenAI 兼容接口地址 |
| `LLM_MODEL` | 是 | 模型标识（如 `generalv3.5` / `deepseek-chat`） |
| `ALLOWED_ORIGINS` | 否 | 允许跨域的前端域名，逗号分隔；同源部署可用 `*` |
| `DB_PATH` | 否 | 错题本 SQLite 路径，默认 `tutor.db` |
| `RAG_ENABLED` | 否 | 是否启用检索增强，默认 `true` |
| `RAG_TOP_K` | 否 | 每次检索返回知识点数，默认 `4` |
| `SPARK_IMAGE_APPID` | 否 | 星火图像理解 AppID（图片问答用，可留空） |
| `SPARK_IMAGE_API_KEY` | 否 | 星火图像理解 API Key（可留空） |
| `SPARK_IMAGE_API_SECRET` | 否 | 星火图像理解 API Secret（可留空） |
| `SPARK_IMAGE_DOMAIN` | 否 | 星火图像理解 domain，默认 `general` |

## 三、启动命令

```bash
uvicorn main:app --host 0.0.0.0 --port 3000
```

启动后访问 `http://<服务器IP>:3000` 即可打开前端页面。

> 本项目同时提供 `run.py`（等价于 `python run.py`，内部同样以 `uvicorn` 启动），二选一即可。

## 四、数据文件位置

| 文件 | 说明 |
|------|------|
| `tutor.db` | SQLite 数据库，含演示合成数据（用户、学习画像、错题本、问答历史、积分等），**不含任何真实个人数据** |
| `knowledge_corpus.json` | RAG 知识库语料（教材知识点分段，553 条） |
| `uploads/` | 静态资源与下载中心文件（APK、竞赛材料等） |
| `seed_data.json` | 种子数据（知识点、题库、示例等） |

## 五、端口与反向代理

- 服务默认监听 **3000 端口**（HTTP）。
- 生产部署建议在 3000 端口前加一层反向代理（Nginx / Caddy / 云平台网关），终止 TLS 并转发到 `127.0.0.1:3000`。
- 反向代理示例（Nginx）：

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    # ssl_certificate / ssl_certificate_key 省略

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

- 流式问答（SSE）接口 `/api/ask/stream` 需要代理开启缓冲关闭：

```nginx
proxy_buffering off;
proxy_cache off;
```

## 六、安全提示

- **严禁**将 `.env` 或任何包含真实密钥的文件打包、上传或提交到公开仓库。
- 本部署包已剔除 `.env`，仅保留 `.env.example`（变量名列表，值全空）。
- 若密钥曾随旧包公开泄露，请立即到对应控制台**轮换新密钥**并更新本地 `.env`。
