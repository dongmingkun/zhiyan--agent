原包共 126 个文件、13,057,523 字节。线上首页及其 24 个已有同源依赖与原包逐字节一致；另行核对的 `metadata.json`、PDF.js 主脚本与 worker、成果下载页也完全一致，合计 29 个已有公开文件匹配。核对的是实际文件的 SHA-256，不是仅比较文件名、时间戳或注释版本号。

2. 删除 2 个被后定义无条件覆盖的方法：`app.v3.19.js` 的早期 `scrollToBubbleTop` 和 `quiz-ui.v3.19.js` 的早期 `_esc`。AST 检查确认保留方法及其他表达式不变。
3. 删除同一父作用域内 8 个完全相同的 CSS 规则，以及 1 条同块重复的 `font-family` 声明。保留后出现的规则及剩余层叠顺序。前端文件和内部冗余清理共减少 374,181 字节。
4. 移除首页重复的 3 条缓存 meta。更新脚本、样式及 Service Worker 缓存标记，避免整理后继续使用旧缓存；缓存清理仅针对本应用前缀。
5. 从当前包移除 APK 1.0.0–1.0.5，以及另一份完全相同的 1.0.6。仅保留 `uploads/downloads/秩研Agent-1.0.6.apk`，首页链接同步更新，旧 1.0.6 下载地址提供 307 跳转。
6. 删除根目录与下载中心逐字节相同的实验报告副本，保留下载中心文件。
7. 删除旧 SFT 的 Alpaca、ShareGPT、stats 三份冗余导出，默认只保留当前 combined；需要时可用导出脚本生成其他格式。

没有把不同字体格式、数学算法、主题规则、移动端补丁或不同 PWA 按钮误判为重复。没有删除原始 553 条知识语料或 347 条问答。所有移除的原始文件均可从原 ZIP 恢复，完整映射见 `audit/SOURCE_MAP.json`。

## 补齐与更新

- 从同一线上站点补回缺失的 180 / 192 / 512 三张应用图标，记录原 URL 与 SHA-256。
- 原 KaTeX 样式引用了 20 个不存在的 TTF 后备字体；线上也返回 404。由 [官方 npm 的 KaTeX 0.16.9 包](https://registry.npmjs.org/katex/-/katex-0.16.9.tgz) 补齐，先确认包内 JS 与 CSS 和原包逐字节相同，再复制字体及许可证。
- SFT 原来来自 20 条 QA、207 条语料的旧快照。现在按当前 347 条 QA、553 条语料生成，补上生成器漏读的 11 条仅有 `text` 的片段；2,494 条候选中去掉 57 条完整字段相同的衍生样本，保留 2,437 条。源数据不变，导出记录输入指纹并可重复生成相同结果。
- 旧 `self_train_state.json` 中的“运行中”是历史快照，已归档；新环境缺失状态时显示未运行。未伪造训练结果。
- 修正维护工具路径和默认输出，防止旧的 17 条前端语料导出、旧小样本 QA 生成器覆盖当前完整数据。

数据更新后 SFT 文件比旧快照大是正常的，代码去重不以压缩包大小持续变小作为唯一目标。

## 运行修复

- 后端、维护脚本、训练工具移动后使用明确项目根路径；从其他工作目录启动也能找到页面与数据。
- 统一 `run.py`、Docker 和 Procfile 的入口，默认端口 8000；数据库备份按 `DB_PATH` 进行 SQLite 一致性备份。
- 补上基础运行所需的 multipart、二维码、WebSocket 等显式依赖，OCR 单独列为可选依赖。
- 修复 PWA 文件路由可被查询参数覆盖文件路径的问题。
- 管理员初始密码改为环境配置，保留现有管理员密码；不再创建固定密码管理员。
- 历史账号种子改为明确开启且仅在空库导入。已有用户与学习记录不再被初始化逻辑清空或替换。
- 旧清库脚本改为显式命令行工具，操作独立输出副本；导入脚本模块不会触发清库。
- Windows 的后台训练进程控制明确返回不支持；原主站功能仍可在 Windows 运行，后台训练控制需 Linux 环境。
