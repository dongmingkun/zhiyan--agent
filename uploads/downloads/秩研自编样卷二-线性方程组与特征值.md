# 秩研自编样卷二 · 线性方程组与特征值

> 秩研 Agent 团队自创题目 · 风格对标线性代数教材课后习题 · 共 5 题

## 一、线性方程组（3 题）

**1.（判断）** 齐次线性方程组 Ax = 0 一定有解（至少零解）。

**2.（填空）** 若 m×n 系数矩阵 A 的秩 r(A) = r，则线性方程组 Ax = b 有解的充要条件是 ______。

**3.（计算）** 求解线性方程组：

$$\begin{cases} x + y + z = 6 \\ 2x - y + z = 3 \\ x - 2y + z = 0 \end{cases}$$

## 二、特征值与特征向量（2 题）

**4.（计算）** 求矩阵

$$A = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}$$

的特征值与对应的特征向量。

**5.（填空）** 若 λ 是方阵 A 的特征值，则 λ² 是矩阵 ______ 的特征值。

---

## 参考答案与解析

**1.** **正确**。齐次方程组 Ax = 0 恒有零解 x = 0，故必有解。

**2.** r(A) = r(A|b)（增广矩阵与系数矩阵同秩）。

**3.** 将增广矩阵化为行最简形，解得 x = 1, y = 2, z = 3（唯一解）。

**4.** 特征多项式 det(λE − A) = (λ−2)² − 1 = λ² − 4λ + 3 = (λ−1)(λ−3)，故特征值 λ₁ = 1、λ₂ = 3。对应特征向量分别为 (1, −1)ᵀ 与 (1, 1)ᵀ（及其非零倍数）。

**5.** A²（因为 A²x = A(Ax) = A(λx) = λ²x）。
