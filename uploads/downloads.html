典型问题测试验证

  • ① 特征值与特征向量　A = [[2,1],[1,2]]　→　λ₁ = 3（v = [1,1]ᵀ）、λ₂ = 1（v = [1,−1]ᵀ）；回代 Av = λv 校验通过，verified = true，符号/数值相对误差 8.88e-16
  • ② 矩阵求逆　同矩阵　→　det(A) = 3，A⁻¹ = [[2/3, −1/3],[−1/3, 2/3]]；SymPy 符号解与 NumPy 数值解一致，verified = true
  • ③ 智能问答　RAG 命中同济六版第四章知识点　→　答案附引用来源与 「AI 生成内容」标识
✅ 全部案例由 SymPy + NumPy 双引擎交叉验证，可运行代码可复现（详见《对比实验报告》）。
